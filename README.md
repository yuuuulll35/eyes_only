# EYES ONLY

PC 곁의 인물을 경계하는 NPC의 관찰 기록, 그리고 그 NPC를 지켜보는 제3자의 감시 기록을 기밀 문서처럼 열람하는 OOC 뷰어 — 빌드 없는 HTML/CSS/JavaScript.

**https://yuuuulll35.github.io/eyes_only/**

## 관찰 방식

| 모드 | 내용 |
|---|---|
| 경계 기록 (MODE 01) | NPC가 PC 곁의 인물을 경계하며 몰래 적은 기록. 지켜보는 NPC와 관찰 대상은 이름을 넣거나 AI에게 맡긴다 |
| 감시 기록 (MODE 02) | PC 주변을 맴도는 NPC를 정체 모를 제3자가 지켜보며 적은 기록 |

## 사용법

1. 관찰 방식을 고르고, 경계 기록이면 누가 누구를 볼지 정한다. 추가 설정에서 PC 이름과 계기 사건을 적을 수 있다.
2. 답이 잘리지 않도록 OOC를 세 번에 나눠 보낸다. 부마다 **OOC 복사** → 채팅에 보내기 → 받은 답을 복사하고 **답 붙여넣기**.

   | 부 | 받는 내용 |
   |---|---|
   | 1부 기본 신상 | 제목, 한 줄 결론, 위험도, 첫인상, 신상, 외관, LIKE·HATE, 관계, 소견, 신빙성 |
   | 2부 관찰 기록 | 사건, 미행, 도청, 성격, 성향 점수, 인물평 |
   | 3부 속마음 | 숨긴 속마음, 열람 불가, 코멘트, 혼잣말 |

   2·3부 요청문에는 1부 답에서 읽은 이름이 자동으로 들어가고, 받은 답은 같은 보고서에 합쳐진다. 덜 받은 보고서는 **이어서 받기**로 마저 받는다.
3. 보고서 목록에서 인물을 눌러 연다. 같은 인물을 다시 검사하면 그 보고서가 새 내용으로 갱신된다.

## 보고서 구성

| 탭 | 내용 |
|---|---|
| 사건 일지 | 관찰이 시작된 사건 타임라인 |
| 신상 정보 | 기본 신상, 인간관계도, 외모와 특징, LIKE·HATE |
| 미행·도청 | CCTV 캡처(사진을 넣으면 브라운관 효과), 재생하면 들리는 도청 기록 |
| 성격 분석 | 첫인상, 성향 레이더, 성격과 행동 습관, 그래서 어떤 사람인가 |
| 숨긴 기록 | 관찰자의 속마음, 세 번 눌러야 열리는 열람 불가 |
| 최종 정리 | 한 줄 결론, 위험도 계기판, 신빙성, 혼잣말 대화창, 종합 소견 |

- 항목마다 확인 · 추정 · 미확인 표시와 관찰자의 구어체 메모가 붙는다.
- 경계 기록은 그 NPC를 지켜본 감시 기록이 생기면 **오해 바로잡기**가 열려, 관찰자가 잘못 안 내용을 항목마다 바로잡아 볼 수 있다.
- 보고서는 이 브라우저에만 저장된다. 목록에서 삭제·백업 저장·백업 반입·전체 파기, 보고서에서 공유 링크 복사를 할 수 있다(서버에 저장하지 않음).
- 예시 보고서의 인물은 모두 성인인 허구의 인물이다.

## 실행

ES 모듈을 쓰므로 `file://`로는 열리지 않는다. 저장소 루트를 그대로 정적 호스팅하거나 로컬에서 띄운다.

```bash
python3 -m http.server 8000
```
